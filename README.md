# گالری سنگ طبیعی — نسخه نهایی یکپارچه

این نسخه برای GitHub Pages + Supabase آماده شده و شامل:
- نمایش محصولات از Supabase
- جستجو و فیلتر دسته‌بندی
- صفحه/پنجره جزئیات محصول
- سبد خرید
- تغییر تعداد و حذف
- ثبت سفارش در Supabase
- پنل مدیریت امن با نقش admin
- افزودن/ویرایش/حذف محصول
- قیمت، موجودی، تصویر، توضیحات و فعال/غیرفعال
- افزودن و حذف دسته‌بندی
- مشاهده سفارش‌ها و تغییر وضعیت سفارش/پرداخت
- داشبورد آمار
- طراحی واکنش‌گرا

## راه‌اندازی
1. فایل `schema.sql` را کامل در Supabase > SQL Editor اجرا کن.
2. در Supabase > Authentication > Users یک کاربر مدیر بساز.
3. UUID همان کاربر را در دستور آخر `schema.sql` جایگزین `UUID_USER` کن و آن دستور را اجرا کن.
4. `config.js` باید Project URL و Publishable/Anon Key را داشته باشد. Secret/service_role را هرگز وارد نکن.
5. همه فایل‌های این پوشه را در ریشه repository گیت‌هاب قرار بده.
6. GitHub Pages را روی branch `main` و root فعال کن.
7. بعد از تغییرات، چند دقیقه برای انتشار GitHub Pages صبر کن.

## قبل از درگاه
ابتدا ثبت سفارش و مدیریت سفارش را تست کن. اتصال زرین‌پال باید بعد از تأیید همین جریان انجام شود؛ کلیدهای خصوصی در GitHub Pages قرار نمی‌گیرند و بخش پرداخت باید سمت سرور/Edge Function پیاده شود.

## ترب
پس از نهایی شدن اطلاعات محصول، قیمت، موجودی، تصاویر و قوانین ارسال، فید/ساختار موردنیاز ترب را جداگانه تنظیم می‌کنیم.
