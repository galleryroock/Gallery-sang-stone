# گالری سنگ طبیعی — نسخه حرفه‌ای و آماده GitHub Pages\n\nفروشگاه لوکس و واکنش‌گرا + سبد خرید + ثبت سفارش واتساپ + ثبت سفارش در Supabase + پنل مدیریت + داشبورد فروش + مدیریت محصولات/دسته‌ها/وضعیت سفارش‌ها.\n\n## راه‌اندازی\n1) در Supabase پروژه بساز.\n2) کل `schema.sql` را در SQL Editor اجرا کن.\n3) Authentication > Users یک کاربر مدیر بساز.\n4) UUID او را با این دستور admin کن:\n```sql\ninsert into public.profiles(id,role) values(\'UUID_USER\',\'admin\') on conflict(id) do update set role=\'admin\';\n```\n5) Project URL و Publishable key را در `config.js` بگذار.\n6) همه فایل‌ها را در ریشه repository گیت‌هاب آپلود کن.\n7) GitHub Pages را فعال کن. پنل مدیریت: `admin.html`\n\nشماره واتساپ در `app.js` متغیر `WHATSAPP` است. Secret/service_role key را هرگز داخل سایت نگذار.\n
